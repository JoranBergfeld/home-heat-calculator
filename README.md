# home-heat-calculator

A React frontend-only calculator for estimating home heating needs per room.

## Features

- Browser-only state with `localStorage` persistence
- Save and load multiple home setups
- Define rooms with name, length, width, and height
- Add doors and windows to each room
- Configure the heat formula in a settings screen
- Simulate heating output from floor heating and central heating

## Development

```bash
npm install
npm run dev
npm run build
npm run test
```
